## 실제 계정·기기 검사

Google 실계정 로그인은 사용자의 OAuth 클라이언트 설정 후 확인해야 합니다. Android Chrome·iOS Safari의 실제 음성 빠르기와 Wake Lock은 실제 기기에서 확인해야 합니다. 자동 테스트가 실제 계정 인증이나 음성 품질을 보장하지 않습니다. 역할 검증은 모의 합성 엔진의 종료 이벤트로 검사했으며 실제 기기의 음소거 음성과 종료 이벤트 지원은 별도로 확인해야 합니다. 브라우저 음성 합성은 잠금 화면·백그라운드에서 중단될 수 있으며 별도 잠금 화면 제어는 제공하지 않습니다.

## 자동 검증 재현

```bash
cd wordStudy_
npm ci
npm run build
npm run verify
node scripts/verify-html.mjs
DATABASE_URL=postgresql://TEST_USER:TEST_PASSWORD@localhost:5432/TEST_DB npm run verify:api
```

Node 24와 PostgreSQL 17을 사용합니다. API 검증은 임시 DB 생성 권한이 필요하며 `wordstudy_verify_...` DB를 생성하고 종료 시 삭제합니다. 운영 자료를 테스트 DB로 복사하지 않습니다.

화면 검증은 저장소 루트에서 fixture 서버를 실행하고 별도 터미널에서 진행합니다.

```bash
python3 wordStudy_/scripts/browser-preview.py
# 별도 터미널
npm install --prefix /tmp/wordstudy-browser playwright
PLAYWRIGHT_MODULE=file:///tmp/wordstudy-browser/node_modules/playwright/index.mjs \
  node wordStudy_/scripts/verify-browser.mjs
```

기본 Chrome 경로는 Linux Google Chrome이며 `CHROME_PATH`로 바꿀 수 있습니다. 화면 검증은 모의 음성 엔진·관리자 화면 조건·팝업 키보드 조작·삭제 자산의 404 응답까지 확인하고 `docs/images/`를 갱신합니다.

## React 아이콘 패널 · 2026-11-23

React 서버 버전의 재생 바는 재생/일시정지·정지·다음 문장·방향 화살표·반복 체크·설정 아이콘을 한 줄로 배치합니다. 모바일 자료 목록은 상단의 자료 선택 팝업으로 옮기고, 학습 메뉴·테마도 한 줄 아이콘으로 표시합니다. 데스크톱은 기존 자료 사이드바와 상단 텍스트 메뉴를 유지합니다. `htmlVersion/`은 이번 화면 변경 대상이 아닙니다.

- 타입 검사·Vite 빌드·`npm run verify` 통과.
- `verify-compact-browser.mjs`: Chrome의 320·390·768·1440px 너비에서 가로 넘침 없음, 하단 한 줄·44px 조작 영역·패널 높이 검증. 선택 팝업 열기/선택/제목으로 이동/Esc, 방향 저장, 반복 켬/끔 토스트, 팝업 안의 설정 토스트, 테마, 문장읽기 일시정지/이어 듣기 검증 통과.
- `verify-browser.mjs`: 설정 팝업·포커스 복원·속도·역할 음소거+3초·정지 스크롤·HTML 버전 회귀 검사 통과. React 스크린샷을 갱신했습니다.
- `verify-study-browser.mjs`, `verify-memorized-browser.mjs`: 학습 횟수·반복 해제·새로고침 유지, 자료 선택 팝업 내 암기 정렬·상태 저장/실패 복원 검증 통과.

운영 반영 후 `BASE_URL=https://rp-yoon.duckdns.org/enWordStudy/`로 동일한 아이콘 화면 검증을 실행해 통과했습니다.

## 데스크톱 고정 재생 바·목록 접기·한국어 설명 · 2026-11-23

- 데스크톱 재생 바를 화면 오른쪽 아래에 고정하고, 대화·문장읽기 본문에 아래 여백을 확보했습니다. 왼쪽 목록은 화살표로 64px 폭까지 접거나 펼치며 접힘 상태를 브라우저에 저장합니다.
- React 학습 설정의 `한국어 설명 읽기`는 기본 켬입니다. 이전 저장 설정에 해당 필드가 없어도 켜집니다. 재생·자동 연속 재생은 상단 설명을 한국어로 먼저 읽고 영어 대사로 이어지며, 화자 버튼은 지정한 대사를 직접 재생합니다. 한국어 설명은 문장 반복·학습 횟수 집계에 포함하지 않습니다.
- `verify-playback.mjs`: 한국어 음성 선택·속도·역할 음소거 제외·설명 후 영어 연결·일시정지/재시작·정지·늦은 이벤트 취소·다음 문장으로 설명 건너뛰기·완주 집계·설정 해제·빈 설명·한국어 오류 시 영어 연결·자동 재생 검증 통과.
- `verify-desktop-playback-browser.mjs`: 768·1024·1440px에서 오른쪽 아래 고정, 스크롤 및 마지막 대사 재생 중 가림 없음, 접기/펼치기·새로고침 저장, 기존 설정의 설명 기본 켬, 한국어/영어 음성 순서, 설정 해제 저장 검증 통과.
- 타입 검사·Vite 빌드·`npm run verify`, 모바일 아이콘·선택 팝업, 기존 역할 재생·정지 스크롤·학습 횟수 브라우저 검증 통과. 한국어 음성 품질은 기기가 제공하는 음성에 따라 달라집니다.

데스크톱 화면 검증은 fixture 서버 실행 후 `PLAYWRIGHT_MODULE`을 지정해 `node wordStudy_/scripts/verify-desktop-playback-browser.mjs`로 재현합니다. `BASE_URL`로 운영 주소를 지정하면 실제 배포 앱에서도 모의 음성·긴 대화 및 원래 자료의 마지막 문장 노출을 검증합니다. `htmlVersion/`과 DB의 학습 자료·인증 설정은 변경하지 않습니다.

운영 HTTPS 주소에서도 데스크톱 고정·접힘 상태·모의 한국어 설명 흐름·실제 자료 마지막 문장 노출과 기존 모바일 아이콘 검증을 통과했습니다. 저장 진도가 중간에 있는 자동 재생에서도 설명 건너뛰기는 첫 대사를 유지하도록 별도 검증했습니다.

## 본문 하단 전체 너비·관리자 전용 학습 기록 · 2026-11-23

- 데스크톱 재생 바는 본문 영역 전체 너비로 화면 아래에 고정합니다. 목록을 접으면 바의 왼쪽 경계도 본문에 맞춰 이동합니다. 문장읽기에서는 왼쪽 패널을 렌더링하지 않고 본문·재생 바가 전체 너비를 사용합니다.
- 학습 횟수·Memorized 체크박스·암기 구분선·암기 정렬은 관리자 로그인에만 표시합니다. 비로그인·일반 사용자의 완주는 기록 요청을 보내지 않습니다. 공개 자료 API에서도 학습 횟수·암기 상태를 제외합니다.
- 횟수 기록·암기 변경 API에 관리자 인증·권한·동일 출처·CSRF를 적용했습니다. 기존 DB의 횟수·암기 상태는 초기화하지 않습니다.
- 타입 검사·Vite 빌드·`npm run verify` 통과. 별도 임시 DB의 `verify-api.mjs`에서 익명/일반/만료 세션 쓰기 차단, 관리자 CSRF·권한 검사, 차단 요청 후 DB 횟수/암기/완료 이벤트 불변, 관리자 정상 기록·중복/동시 완료·마이그레이션·재시작 보존 검증 통과. 운영 자료를 테스트 DB에 복사하지 않았습니다.
- `verify-admin-visibility-browser.mjs`에서 익명/일반/관리자 화면 표시·완주 요청 유무·관리자 암기 변경·문장읽기 전체 너비를 확인했습니다. `verify-desktop-playback-browser.mjs`, `verify-compact-browser.mjs`, 관리자 세션을 모의하는 기존 학습 횟수·암기 상태 브라우저 검증도 통과했습니다.
- React 화면 캡처를 갱신했습니다. `htmlVersion/`은 별도 정적 실행 방식으로 이번 변경 대상이 아닙니다.

운영 HTTPS에서도 권한별 화면 검증과 본문 너비의 고정 바·문장읽기·실제 자료의 마지막 문장 노출 검증을 통과했습니다. 실제 공개 API 응답에서 관리 필드가 빠지고 비로그인 변경 요청은 401로 거절되는 것을 확인했으며, 자료 84개와 블로그 첫 화면을 보존했습니다.

## 음성 0개 재생 알림 · 2026-11-23

React 대화연습·선택 재생·문장읽기의 재생/이어 듣기는 클릭 시 현재 음성 목록을 다시 확인합니다. 사용 가능한 영어 음성이 0개이면 `재생할 목소리가 없습니다.` alert을 표시하고 재생·완주 기록·자료 전환을 시작하지 않습니다. 음성이 늦게 준비되고 `voiceschanged` 이벤트가 오지 않아도 다음 클릭 시 다시 확인해 사용합니다. `htmlVersion/`의 정적 실행 방식은 변경하지 않았습니다.

- 타입 검사·Vite 빌드·`npm run verify` 통과. 재생 hook에서 음성 0개 알림·재생/이어 듣기 차단·늦은 음성 준비를 검증했습니다.
- `verify-no-voice-browser.mjs`에서 빈 음성 목록을 모의하여 대화·선택 재생·문장읽기의 alert 문구, 재생/완주 기록/자료 전환 차단, 일시정지 후 음성이 없을 때 이어 듣기 차단, 음성 준비 후 정상 재생을 검증했습니다. 실제 Firefox의 음성 설치·지원 여부를 변경하는 기능은 아닙니다.

운영 HTTPS 주소에서도 같은 빈 음성 목록 시나리오를 재현해 alert·재생 차단·음성 준비 후 재생 검증을 통과했습니다.
